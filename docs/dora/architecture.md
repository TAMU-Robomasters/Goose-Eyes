# Architecture

One diagram per dataflow in `goose-eyes/dataflows/`, generated by `dora graph <yml> --mermaid` into
`docs/generated/` (`pixi run docs-gen`; the `docs` and `docs-serve` tasks run it first). Don't edit the
diagrams by hand — change the YAML and regenerate. Node ids in the diagram are the `id:` fields in the
YAML; the script each id runs is listed in the table below.

The one edge today carries a flattened BGR frame as a `pyarrow` `uint8` array with `shape` and `time`
in the metadata (see [camera_pub](nodes/camera_pub.md)).

## `dataflow.yml` — camera pub/sub demo

`dora run goose-eyes/dataflows/dataflow.yml` (inside `pixi shell`, or prefixed with `pixi run`). One
capture node, one display node reading its output over shared memory.
